# JDX 0.2.1 — 京东设置页单击入口

0.2.0 仅通过双指长按进入 JDX。用户报告页面紧凑，手势难以成功。

- 京东「我的 → 设置」中，在识别的原生设置页导航栏右上方追加 **JDX** 单指按钮，保留所有已有的右侧按钮。
- 对于没有可见系统导航栏的已识别设置页，在页面右上安全区显示 44pt 高的 **JDX 设置** 备用按钮。
- 有限深度扫描可见容器的标题或常见精确控制器名称，不读取设置单元格文字、账号或页面内容；不替换京东列表数据源、不 Hook UIKit 通用生命周期方法。
- 共用 JDX 原有设置页、14 项开关、诊断和日志导出；双指长按仍可使用。总开关关闭时也能打开入口。
- 每秒轻量检查当前可见页面，导航/浮动按钮的关联对象确保不重复创建；新增入口附带固定标记的本地诊断事件。

## 验证与限制

新 Foundation 原生单元测试覆盖中英文标题、已识别类名及非设置页误匹配；原有 arm64 编译、签名和业务回归测试仍由 GitHub Actions 执行。由于本轮没有新京东 IPA 或真实设置页导航结构，本入口属于**待真机验证的最佳兼容实现**；如果最新版页面由 H5/Flutter/自绘导航呈现、标题不在 UIViewController 上，可能需要实际截图及 IPA 做精准适配。
