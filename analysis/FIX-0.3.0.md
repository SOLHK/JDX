# 0.3.0 修复与验证记录

本次修复已确认的设置入口探测遗漏、关闭规则却仍在启动或检查时安装业务方法、旧版全部拦截配置隐藏正常推荐等问题。**搜索、购物车、订单、客服与视频页的全局联网失败仍待真机对照；当前证据不能证明它们已被全部修复，也不能确定服务端或账号状态。**

报告中的宿主版本字段为 `171204 / 16.1.83`，插件版本为 `0.2.1`。可确认：

2. 设置三次经 `two_finger` 打开，来源均为 `JDTabBarController`。增强诊断只观察到主容器和系统弹窗等少数页面，没有识别到截图中实际打开的设置页。

## 业务方法安装与纯净会话

0.2.1 的安装函数只检查版本兼容性，关闭总开关或单项仍会安装全部业务 Hook；“关闭”仅让替换后的包装器透传。诊断检查也调用安装函数，可能在用户对照时改变待检查状态。

0.3.0 将安装条件明确为：主线程、兼容版本、本次会话非纯净、用户当前未请求纯净、总开关开启、对应位置请求启用。关闭的规则不会改写宿主 IMP，也不消耗延迟加载重试次数。

- `session_safe_mode` 在配置初始化时捕获本次启动模式，后续 profile、master 和单项开关不能修改它。
- `safe_mode` 表示用户保存的启动选择；`restart_required` 表示该选择与当前会话不同。
- 纯净会话中关闭纯净模式，当前进程仍保持零业务 Hook，必须彻底退出并重开才会启用拦截。
- 普通会话中开启纯净模式，已有包装器立即透传；仍需重启才能形成零业务方法替换的会话。
- 普通会话关闭总开关仍是透传，不声称已卸载方法。总开关关闭状态下冷启动则不安装；该普通会话稍后主动开启总开关，可安装所选规则。
- 冷启动、前台通知、配置变更及延迟重试共用安装门控。运行诊断和导出只观察状态，不安装或重装方法。
- `home.bottom-all` 可在 `home.bottom-ad` 关闭时独立请求共享方法；首页推荐仍要求配对方法存在、签名匹配且两个原实现均就绪。

报告同时保留用户选择、已安装数量、当前入口是否匹配和配对就绪状态。不能把“配置开启”直接等同于“方法已安装且正在执行”。

纯净模式仍运行 JDX 设置、日志与被动系统路径观测；“零业务 Hook”只描述本插件的业务方法替换，不表示没有加载 dylib，也不替其他插件或宿主环境作保证。

## 一次性配置迁移

配置 schema 升为 3。首次安装或 `schema < 3` 升级时保存纯净模式开启。

仅当旧 schema 为 2、14 项全部开启时，迁回推荐配置，避免原有全部拦截继续隐藏正常推荐；已有总开关值保持不变。备份保存在 `com.solhk.jdx.migration.schema3`，只含原总开关和规则布尔值，不复制京东其他偏好或账号数据。

其他自定义组合保留。后续 schema 3 启动使用用户保存的模式和开关，不重复迁移，也不覆盖先前备份。较新的 schema 标记不会被降级。

## 设置入口

入口发现补充了可见视图 responder 链，处理自定义容器未提供标准控制器层级的情况；遍历有节点、深度与对象身份限制。对自绘导航只临时比较顶部固定设置标题，避免将其他页面中的普通设置行当作设置页。

已识别的京东设置页提供单指 JDX 入口：标准导航栏追加“JDX”，自绘设置页在确认空闲的位置放置“JDX 设置”；已有按钮与可用空间不足时使用备用入口。窗口内另有可拖动、保存位置的 JDX 备用按钮，原双指长按手势保留，不创建额外 UIWindow。备用按钮在键盘、系统弹窗／分享／文件或图片选择、本插件面板及非活跃状态隐藏，返回正常页面后恢复。设置入口独立于业务总开关、纯净模式和版本适配。实现不改写京东设置列表数据源，也不 Hook 通用 `UIViewController` 生命周期。

入口诊断保留固定状态、页面类名和必要的数量信息，不保存或导出检视过的页面文字。真实显示、遮挡避让和自定义页面切换仍需真机验证。

## 被动系统网络路径观测

新增 `JDXConnectivity`，使用系统 Network 框架的路径监测。它不发起请求、不枚举目标服务、不修改代理或证书、不替换京东网络方法。

状态包含 `waiting`、`satisfied`、`unsatisfied`、`requires_connection` 等，以及 Wi-Fi／蜂窝／有线等接口类型布尔值、受限／高成本网络标记、DNS／IPv4／IPv6 支持布尔值和固定的不可用原因代码。

**`satisfied` 仅表示系统路径可用。** 它不证明 DNS 查询成功、代理能转发、京东接口能访问、账号有效或服务端正常。导出中明确固定 `service_connectivity=not_tested`，用于防止把系统路径误当作京东服务探测结果。

不记录接口名称、网关、IP 地址、URL、请求／响应正文、Cookie、token、账号、订单或页面文字，不自动上传。日志限额和后台导出沿用原实现。

| 步骤 | 需要确认的结果 |
